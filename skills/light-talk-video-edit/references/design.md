# 浅色包装设计规范

这套规范定义默认的浅色口播包装，可随品牌或后续反馈调整。

需要直观核对构图时，查看 [浅色版式参考](../assets/style-reference.jpg)。图中使用抽象示意内容，不含用户原片或固定案例。

## 颜色与层级

| 用途 | 默认色 |
|---|---|
| 画布 | 米白 `#F7F7F1` |
| 卡片 | 白 `#FFFFFF` |
| 正文、标题 | 深灰绿 `#283F3C` |
| 强调、图标、连接线 | 鼠尾草深绿 `#376F62` |
| 辅助色 | 浅绿 `#AAC4B4` |
| 少量暖色点缀 | 杏色 `#D49C7F` |
| 次要文字 | `#7D8B83` |

使用明显的字号差而非大量描边区分层级。720×1280 工程的参考值：主标题 55–65 px，说明 24–28 px，字幕约 34 px，微型英文和来源 13–18 px。长标题需要降字号或换行，不能超过卡片。次要文字仍须在手机尺寸下可读。

以留白、细分隔线、轻微纸色渐变和软阴影建立层次。减少深色网格、荧光边缘、粗金框和整屏装饰线。阴影只用于区分前后，避免每个对象都有明显浮起效果。

## 构图

- 人物段：顶部小栏目签，必要时出现浅色标题卡。标题避开头发、眼睛与手势；不需要强调的句子只留字幕。
- 资料照片：浅色画布上放圆角照片卡，配清楚的标题；人物小窗可浮在照片的一角。横图先做取景，图片推拉要慢且范围小。
- 连接图：中心对象明确，节点、箭头依次出现；已出现的对象保持位置，避免反复跳动。
- 并列卡：主卡承载主体，次级小卡分组进入。图标的笔画和尺寸一致，短标签优先于段落。
- 确定性/制度类：可用简洁纸艺建筑或概念图，下面用逐项列表；根据新主题更换象征，不能对所有口播都强行画法院。
- 人物窗：白色细边、圆角、轻阴影，头部与下巴留余量。尺寸参考画面宽度的约 25%–30%，以人物清楚和不遮挡为准。
- 字幕：浅底深字胶囊，重点词少量用绿色。通常最多两行，过长就按语义和实际发音拆成多个事件；避免一个字留在下一行。
- 片尾：干净的留言/行动卡，和整片卡片系统一致。CTA 采用用户提供或原片已经说出的内容。

## 动效

普通图层用约 0.3–0.5 秒的短渐入及轻微上移作为起点。新对象入场后保持稳定，只有需要强调局部时才放大。跨画布切换用短溶解，普通话语衔接保持直切或小幅景别变化。

不要把所有段落都做成同一种三列卡：连接图、叠层主卡和纵向列表应有构图差异，但沿用同样的颜色、圆角、字体和图标体系。

## 可读性检查

将关键画面缩到手机宽度查看：标题是否一眼能识别、字幕是否压住人物、最小标签能否读清。浅色主题需要深色正文；装饰性淡色插画可以低对比度，承载信息的文字和连接关系不能依赖这种低对比度。
