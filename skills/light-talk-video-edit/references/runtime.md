# 本地运行环境与语音识别

附带渲染器依赖 Python、Pillow、NumPy 和含 H.264/AAC 编码器的 FFmpeg；字体需覆盖所用语言。它不依赖 MoviePy，也不需要把原片上传给转录服务。

优先复用已有工具。Codex 桌面提供 `load_workspace_dependencies` 时，可查找绑定的 Python 与库路径；不要把开发本技能时的用户名、缓存版本或磁盘路径写进新项目。FFmpeg 通过配置、`FFMPEG_EXE` 环境变量或 PATH 发现。Windows 可从当前已知工具目录定向查找，避免扫描整个用户目录。

示例字体为 Windows 的微软雅黑、Arial、Georgia；渲染器也接受显式字体路径。在其他系统选具备中文字符的字体。英文数字可用拉丁字体，但混合中文的标签必须使用中文字体，防止方框缺字。

## 语音转录

已有可靠字幕或文稿时优先使用。需要本地识别时可用 Whisper CLI 或其他可用转录引擎。先提取标准单声道 WAV：

```text
ffmpeg -i 原片.mp4 -vn -ac 1 -ar 16000 -c:a pcm_s16le speech.wav
whisper-cli -m 中文或多语言模型.bin -f speech.wav -l zh -osrt -otxt -ojf -of transcript
```

具体开关先读取当前 CLI 的 `--help`。模型放在工具缓存或当前工作区，不打包进技能。中文模型不能误用英语专用 `.en` 模型。

转录文本存在同音词、口音词和时间漂移：以原声核对姓名、金额、否定词和重复句。识别输出中的单词级时间不是必然准确的剪刀点；结合波形、停顿和前后试听确定删减位置。只做包装改版时，不必重新转录或改变已经确认的文稿。

确实缺工具时再获取官方发布或可信软件仓库的组件，保存来源并核对可用的摘要。运行环境需要联网权限时走正常的工具授权，不反复尝试无关服务。技能包不内置 FFmpeg 二进制、ASR 模型、系统字体或用户原片。

若自动生成了字幕但当前环境无法听辨，应明确剩余核对点，不宣称已听审通过。
