# 排版与分镜

## 信息结构

先把台词拆成语义单元，不是每句话单独套卡片。适合25秒样片的一种安排：问题约3秒、反差约4秒、提问约2秒、判断标准约5秒、证据约7秒、真人结论约4秒。这只是分配示例，不是必须凑齐的章节或固定时间。

- 对照：同一维度并列；共用对齐轴，结论侧更大、更深，另一侧弱化。不要把“甲与乙不同”画成“甲导致乙”。
- 顺序：步骤编号和有方向的连接；已讲节点缩小上移，当前节点突出。
- 公式：操作数、运算符、结果分层；随口播逐项展开，结果最后出现。单位、假设和基准不要丢。
- 证据：先讲判断标准，再展示相关证据。保留“可能”“假设”等限定词，不把口播观点包装为已核实事实。

## 字体和版面

默认暖纸色底、墨绿重点、砖红反差、哑金点缀。纸纹很轻，不用巨大底纹字挤占阅读空间。

720×1280逻辑画布，四周约48px。按句长与人物构图调整以下层级：

| 层级 | 建议逻辑字号 | 用途 |
|---|---:|---|
| 主词/数字 | 70–90 | 当前唯一主判断 |
| 标题 | 44–60 | 本段问题或结论 |
| 解释 | 22–30 | 关系、条件、归属 |
| 栏目/来源 | 16–20 | 次要导航 |
| 字幕 | 27–30 | 实际口播，不与主词抢层级 |

思源宋体Heavy用于少量展示标题，思源黑体Medium用于标签、解释和字幕。长标题先精简、换行，再合理缩字，不把整行挤成小字。不要所有文字同样大、同样粗，也不要弱化重要条件。

主体以左轴对齐，双列比较共用顶部和基线。相同信息用相同间距。线和箭头表达真实关系，不作装饰。人物框、字幕区和图解内容分区，不靠最后覆盖字幕掩盖冲突。

## 运动与声音

入场约0.25–0.45秒，以位移和透明度为主，少量缩放强调。重点词在对应词义开始附近出现，不长期提前暴露下一结论。指向线和下划线随语义展开。检查转场起点、中点、终点，不只检查成型帧。

真人开场、图解小窗、真人收尾形成节奏，不要求每段都切景。人物放大时字幕稳定，不给人物面部做未经需要的重绘。

字幕可纠正“头票/投票”等明显同音识别错误，不补未说过的内容。保留关键否定和可能性用语。涉及资金、政策等事实论证时，不新增未经核实的数据。

仅原声也能完成此风格。音效应轻，真实配乐需许可明确、音量低于口播，并在工程记录来源。
