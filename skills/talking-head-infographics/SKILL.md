# 口播图解剪辑

用原声口播串起「提出问题 → 解释关系 → 强调结论」，让观众一眼看清本句重点。保存的是视觉语言和可执行渲染工具，不是固定主题、固定台词或全自动选素材软件。

## 范围与默认值

- 默认先做约25秒、9:16、1080×1920、30fps样片，原速、原声。用户指定时长、速度、完整制作或已有本条样片确认时，以其要求为准。
- 新建输出目录；保留原片和旧版。交付MP4、SRT、计划JSON及检查结果；JSON和脚本可修改，但不是剪映、PR或AE原生工程。
- 素材留在本机。云端转写、购买素材、发布或上传私人视频不由本技能自动授权。复刻参考中的视觉语言，不假装拥有其分层工程。

## 工作流

1. **先理解内容。** 探测视频、抽帧检查脸部和空白区；用本地ASR或用户已有时间码稿转写。核对数字、专名、否定和条件词。剪重复起句或停顿时保留原意和顺序，切点避开字音。没有听过音轨就不要声称已逐秒试听。
2. **决定图解关系。** 每段先写一句「观众应理解什么」，再选择对照、顺序、公式、因果或证据结构。箭头必须有意义；对照不画成因果。没有数字的口播不要硬加数字卡片；假设值要明示。情绪、观点、证据不能混排为同一等级。
3. **建立主次与时钟。** 读取 [排版与分镜](references/style.md)。每屏只突出一个主判断；章节标题、主词、解释、字幕分级。思源宋体标题与思源黑体说明是本风格起点，也可依品牌改字体。关键结论放大，重复信息删减。人物小窗给图解让位，但保留可辨表情的尺寸。
4. **写当期计划。** 读取 [计划格式与命令](references/project-format.md)，改写 [示例计划](assets/example.plan.json)。分镜、字幕、字效时间均使用剪切后的输出时间，不混用原片时间。剪辑或速度变化后重对时间；素材已变速时不得再乘一次默认速度。随附脚本不自动变速，需先生成音画同步、保留音调的底片。
5. **先看关键帧。** 使用preview模式，检查完整图解、长标题和转场前中后。确认主词突出、关系正确、对齐统一、中文不缺字、字幕不遮嘴、文本不被人物框遮挡。不要只看缩略图；挑重点屏放大查看。
6. **渲染和检查。** 本地FFmpeg+Pillow工具支持文字、线、箭头、块、图片、人物窗口和原声音轨。导出后完整解码，检查准确时长、帧数、剪切同步和实际AAC响度。建议原声约−16 LUFS、峰值低于−0.5dBTP；实际听感优先。默认不加背景音乐；用户需要时使用许可明确的真实曲目，记录来源，保持人声主导，不把测试音或默认合成音当成已选配乐。

## 工具与交付

需要Python 3.10+、requirements.txt中的库，以及可用FFmpeg；渲染器也可使用imageio-ffmpeg自带二进制。不依赖私有模板、特定操作系统字体或上一次聊天。

字体可用scripts/fetch_fonts.py下载官方开源文件到本期工程；网络不可用时使用已授权的本地中文字体并填写计划路径。原片、字体缓存、模型和输出不需要提交到技能仓库。

提供可播放成片，简述实际更改、时长和检查范围。后续按反馈另存版本，复用已确认的剪辑、字幕和声音。源码路径和制作参数不能替代用户可直接查看的MP4。
